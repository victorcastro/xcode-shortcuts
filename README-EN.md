## ✏️ Editing & Formatting

**Re-indent code**  
`⌃ + I`

**Move line up**  
`⌥ + ⌘ + [`

**Move line down**  
`⌥ + ⌘ + ]`

**Split current file**  
`⌥ + ⌘ + ,`

---

## 🔧 Refactoring

**Edit / rename all occurrences in scope**  
`⌃ + ⌘ + E`

**Generate memberwise initializer**  
`⌥ + ⌘ + Click`

---

## 🔍 Search & Navigation

**Quick Open (Open Quickly)**  
`⇧ + ⌘ + O`

**Search in current file**  
`⌘ + F`

**Search in entire project**  
`⌘ + ⇧ + F`

**Search & replace (current file)**  
`⌥ + ⌘ + F`

**Jump to line**  
`⌘ + L`

**Jump to definition**  
`⌃ + ⌘ + Click`

**Find symbol in workspace**  
`⇧ + ⌃ + ⌘ + F`

**Call hierarchy**  
`⇧ + ⌃ + ⌘ + H`

**Jump to file (jump bar)**  
`⌃ + 5`

**Jump to method**  
`⌃ + 6`

**Reveal file in Project Navigator**  
`⇧ + ⌘ + J`

---

## 🖱️ Multicursor & Selection

**Multicursor (multiple cursors with click)**  
`⇧ + ⌃ + Click`

**View hierarchy lookup (Storyboard/XIB)**  
`⌃ + ⇧ + Click`

---

## 🐞 Debugging & Breakpoints

**Toggle breakpoint on line**  
`⌘ + \`

**Enable/disable all breakpoints**  
`⌘ + Y`

**Jump to next error/warning**  
`⌃ + ⌘ + '`

---

## 📂 Tabs & Panels

### Tabs
**New tab**  
`⌘ + T`

**Switch tabs**  
`⌃ + Tab`

**Close tab**  
`⇧ + ⌘ + W`

### Left Panel (Navigator)
**Switch navigator sections**  
`⌘ + (1–9)`

**Show/hide navigator**  
`⌘ + 0`

### Right Panel (Inspector)
**Switch inspector tabs**  
`⌥ + ⌘ + (1–7)`

**Show/hide inspector**  
`⌥ + ⌘ + 0`

### Library
**Show Library (snippets, assets, UI components)**  
`⇧ + ⌘ + L`

---

## 📁 Files & Project

**Open file in Assistant Editor**  
`⌥ + ↩`

**Open file in alternate Assistant Editor panel**  
`⇧ + ⌥ + ↩`

**Open dependency in Assistant Editor**  
`⌃ + ⌥ + ⌘ + ↩`

**Create new group**  
`⌃ + ⌥ + ⌘ + N`

**Open Xcode preferences**  
`⌘ + ,`

---

## 🧹 Build & Clean

**Clean project (partial Derived Data reset)**  
`⌘ + ⇧ + K`

---

## 📖 Documentation

**Insert documentation template**  
`⌘ + ⌥ + /`

**Open Apple documentation for selected symbol**  
`⌃ + ⌥ + ⌘ + /`

---

## 🛠️ Schemes & Tools

**Open scheme selector**  
`⌃ + 0`

**Code review mode (Diff mode)**  
`⇧ + ⌥ + ⌘ + ↩`

**Commit changes**  
`⌥ + ⌘ + C`

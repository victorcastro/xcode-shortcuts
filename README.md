## ✏️ Edición y Formato

**Reindentar código**  
`⌃ + I`

**Mover línea hacia arriba**  
`⌥ + ⌘ + [`

**Mover línea hacia abajo**  
`⌥ + ⌘ + ]`

**Dividir el archivo actual (split)**  
`⌥ + ⌘ + ,`

---

## 🔧 Refactorización

**Editar / renombrar todas las ocurrencias en el mismo scope**  
`⌃ + ⌘ + E`

**Generar inicializador memberwise**  
`⌥ + ⌘ + Click`

---

## 🔍 Búsqueda y Navegación

**Búsqueda rápida (Open Quickly)**  
`⇧ + ⌘ + O`

**Buscar en el archivo actual**  
`⌘ + F`

**Buscar en todo el proyecto**  
`⌘ + ⇧ + F`

**Buscar y reemplazar (archivo actual)**  
`⌥ + ⌘ + F`

**Ir a una línea específica**  
`⌘ + L`

**Ir a definición**  
`⌃ + ⌘ + Click`

**Buscar símbolo en workspace**  
`⇧ + ⌃ + ⌘ + F`

**Ver jerarquía de llamadas**  
`⇧ + ⌃ + ⌘ + H`

**Saltar a archivo (jump bar)**  
`⌃ + 5`

**Saltar a método**  
`⌃ + 6`

**Resaltar archivo en Project Navigator**  
`⇧ + ⌘ + J`

---

## 🖱️ Multicursor y Selección

**Multicursor (múltiples cursores con clic)**  
`⇧ + ⌃ + Click`

**Mostrar jerarquía de vistas en Storyboard/XIB**  
`⌃ + ⇧ + Click`

---

## 🐞 Depuración y Breakpoints

**Activar/Desactivar breakpoint en la línea**  
`⌘ + \`

**Activar/Desactivar todos los breakpoints**  
`⌘ + Y`

**Ir al siguiente error/advertencia**  
`⌃ + ⌘ + '`

---

## 📂 Pestañas y Paneles

### Pestañas
**Nueva pestaña**  
`⌘ + T`

**Cambiar de pestaña**  
`⌃ + Tab`

**Cerrar pestaña**  
`⇧ + ⌘ + W`

### Panel izquierdo (Navigator)
**Cambiar de sección (Project, Issues, Reports…)**  
`⌘ + (1–9)`

**Ocultar/mostrar panel izquierdo**  
`⌘ + 0`

### Panel derecho (Inspector)
**Cambiar inspector (File, Identity, Connections…)**  
`⌥ + ⌘ + (1–7)`

**Ocultar/mostrar inspector**  
`⌥ + ⌘ + 0`

### Biblioteca
**Mostrar Library (snippets, colores, assets)**  
`⇧ + ⌘ + L`

---

## 📁 Archivos y Proyecto

**Abrir archivo en el Assistant Editor**  
`⌥ + ↩`

**Abrir archivo en otro panel del Assistant Editor**  
`⇧ + ⌥ + ↩`

**Abrir dependencia en Assistant Editor**  
`⌃ + ⌥ + ⌘ + ↩`

**Crear nuevo grupo en el proyecto**  
`⌃ + ⌥ + ⌘ + N`

**Abrir preferencias de Xcode**  
`⌘ + ,`

---

## 🧹 Compilación y Limpieza

**Limpiar el proyecto (Derived Data parcial)**  
`⌘ + ⇧ + K`

---

## 📖 Documentación

**Añadir plantilla de documentación**  
`⌘ + ⌥ + /`

**Buscar símbolo en la documentación de Apple**  
`⌃ + ⌥ + ⌘ + /`

---

## 🛠️ Esquemas y Herramientas

**Abrir selector de schema**  
`⌃ + 0`

**Modo revisión de código (Diff mode)**  
`⇧ + ⌥ + ⌘ + ↩`

**Commit de cambios**  
`⌥ + ⌘ + C`
